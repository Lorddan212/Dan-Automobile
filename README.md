# DanAuto

Premium futuristic automobile website built with React, Vite, Tailwind CSS, Framer Motion, and React Router.

## Features

- Luxury dark interface with glassmorphism, layered gradients, and premium spacing
- Multi-page experience with routed Home, About, Services, Gallery, Cars, Car Details, and Contact views
- Reusable components, scroll animations, tilt interactions, and loading screen
- Responsive layouts for mobile, tablet, and desktop

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
